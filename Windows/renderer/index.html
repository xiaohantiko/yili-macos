      四柱如何排出

      输入 1901–2099 年的公历出生日期、钟表时间和出生时区。时区采用当地历史时差与夏令时，重复出现的时刻取第一次。

      年柱于立春换年，月柱于十二个「节」交节时切换。节气表依据 JPL DE440 星历预先计算，以 UT1 近似民用时间。输入时间按所填分钟的起点处理。

      日柱在出生地的民用午夜切换。子时从 23:00 开始，时干取当时所属民用日的日干。
